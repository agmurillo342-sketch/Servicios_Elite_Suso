# Servicios Elite Suso

Landing page de una sola página para presentar servicios de personal para eventos.

## Desarrollo local

No requiere dependencias ni proceso de compilación. Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático.

## Antes de publicar datos comerciales

Confirma el catálogo definitivo de servicios y agrega los canales de contacto oficiales del negocio. El formulario actual genera y copia una solicitud sin enviar información a terceros.
